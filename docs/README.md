# Geometric Lib

This is library with geometric functions.

## Functions:

* `area(r)` - returns area of the circle with radius r
* `perimeter(r)` - returns perimeter of the circle with radius r
* `area(a)` - returns area of the square with side a
* `perimeter(a)` - returns perimeter of the square with side a
* `area(a, h)` - returns area of the triangle with base a and height h
* `perimeter(a, b, c)` - returns perimeter of the triangle with sides a, b, c
* `calculate(a, b, operation)` - performs arithmetic operation on a and b

# How to use calculator:
1. Run `python calculate.py`
2. Enter the figure name. Available are Circle, Square.
3. Enter the function: Area or Perimeter.
4. Enter figure sizes. Radius for circle, one side for square.
5. Get the answer!

# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = sqrt(p * (p-a) * (p-b) * (p-c)) where p is semiperimeter

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
